# The Missing Necklace - Interactive Detective Mystery Game

An interactive detective mystery game built using Python and Tkinter where players solve the case of a missing necklace.

### Story
Players must investigate locations, interview suspects, examine evidence, follow the timeline, connect clues, and ultimately solve the mystery.

### Features
- Investigate multiple locations
- Interview suspects
- Examine evidence
- Timeline tracking
- Clue connection system
- Interactive decision-based gameplay
- Mystery solving mechanics

### Tech Stack
- Python
- Tkinter (GUI)
- AI-assisted development workflow

### How to Run
1. Clone this repository:
   git clone https://github.com/EmanFatima-00/the-missing-necklace-detective-game.git

2. Run the game:
   python detective_game.py
